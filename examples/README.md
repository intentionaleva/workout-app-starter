# Examples

| Folder | What it is |
|---|---|
| [`evas-plan/`](evas-plan/) | The plan this app was built for: a daily morning routine, two strength workouts, cardio check-off and a postpartum circuit. 28 animated exercises. It's also what `config/` ships with. |
| [`blank-starter/`](blank-starter/) | The smallest useful setup: one routine, three text-only exercises. Start here if you want to build your plan from scratch. |
| [`library/`](library/) | Extra exercises to copy into your own `config/exercises.js`. Contributions welcome, see [CONTRIBUTING.md](../CONTRIBUTING.md). |

To use an example, copy its `exercises.js` and `routines.js` over the ones in `config/`.
All examples are checked by `npm run check`.
