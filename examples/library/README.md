# Exercise library

Exercises you can copy into your `config/exercises.js`. Each one is self-contained (no `extends` to
exercises outside this file).

| id | Kind |
|---|---|
| `forearm-plank` | animated, hold |
| `air-squat` | animated |
| `calf-raise` | animated |
| `jumping-jacks` | text-only (no animation yet; a good first contribution) |

Open [the pose editor](../../editor.html) and pick "Library" to preview them.
